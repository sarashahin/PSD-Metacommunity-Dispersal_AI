# `scripts/` — Metacommunity-generation sweeps & ecological checks

![project badges](badges.svg)

Helper scripts around **Stage 1** (the individual-based metacommunity simulation): they
generate the training/eval "metacommunities" by sweeping simulation parameters, list metacommunity
parameters, and run ecological sanity checks on the produced `*_training.npz` files.

> These scripts call **`run_all_rps.py`** from `../infinite_pool_simulation/`. In this
> repo that simulation code is a set of **placeholder stubs** (the real simulator lives
> in the author's local workspace), so the sweeps here document the exact invocation but
> need the real Stage-1 code present to actually run. See
> [`../infinite_pool_simulation/README.md`](../infinite_pool_simulation/README.md).

## Metacommunity-generation sweeps

`sweep_worlds*.py` are GPU-aware drivers (one worker per visible GPU via
`CUDA_VISIBLE_DEVICES`, CuPy fallback) that loop over a parameter grid and call
`run_all_rps.py` once per combination.

```bash
# From the directory containing run_all_rps.py (the Stage-1 sim):
python scripts/sweep_worlds.py                 # full training grid
python scripts/sweep_worlds_eval30.py --limit 1   # AUTO-GENERATED by design_unseen_eval_worlds.py; smoke-test one world
python scripts/sweep_worlds_eval30.py             # full 30-world unseen-eval sweep
```

Parameter grid in `sweep_worlds.py` (produces the `pool22510000_batcha_ls*_vr*_thr*_env*_grid20x20_dr*_ld*_training.npz` names):
`LENS=[2.5,5,10]` (env length scale), `VARS=[0.001,0.002,0.004]` (env variance),
`THRS=[1,3,5]` (competition threshold), `SEEDS=[123,456]` (env seed — note the unseen
set uses **789/2024**), `DRS=[2e-8,5e-8,1e-7]` (dispersal rate),
`LDD=[0.0,0.06,0.12,0.2]` (long-distance dispersal prob). The base command is
`run_all_rps.py --pool 22510000 --skip-psd --skip-ode --tmax 10000 --record 200
--save-env-field --ibm-record-mode full ... --obs-budgets 1,5,10,20,50,100`.

Variants: `sweep_worlds_eval30.py` (unseen eval), `sweep_worlds_highmix.py` (high
dispersal), `sweep_worlds_missing5.py` (fill gaps), `sweep_worlds_eval30.py`
(auto-generated). `list_world_params.py --root <dir>` prints D / LDD / extant-species
per metacommunity. `infinite_pool_plots.py` renders infinite-pool summary plots.

## `ecological_checks/` — validation of produced metacommunities

Run against a folder of `*_training.npz` metacommunities (no GPU required unless noted):

```bash
# central loader / catalog (used by the others)
python scripts/ecological_checks/load_training_worlds.py --root results/data --summarize
python scripts/ecological_checks/load_training_worlds.py --root results/data --quicklook --max-worlds 1
```

| Script | Checks |
|---|---|
| `load_training_worlds.py` | `DataCatalog` — lazy `.npz` loader (indexes only `*_training.npz`), summaries & quick-look plots |
| `check_equilibrium_timeseries.py` | Communities reached equilibrium (time-series) |
| `check_competition_sinks.py` | Competitive-exclusion sinks |
| `check_connectivity_dual.py` | Spatial connectivity (dual metric) |
| `check_detection_sensitivity.py` | Detection sensitivity vs observation budget |
| `compare_dispersal_regimes.py` | Compare low/high dispersal regimes |
| `ofd_logseries_ibm.py`, `ofd_logseries_ibm_subsample.py` | Occupancy-frequency / log-series fits |
| `inspect_ranges.py`, `plot_example_ranges.py` | Species range-size inspection & example maps |
| `inspect_lifebird_tif.py` | Inspect a LifeBird GeoTIFF (empirical reference) |

Most take `--root`/`--sim-dir` pointing at the metacommunities directory; run with `-h` for the
exact flags. `load_training_worlds.py` requires numpy (and optionally CuPy/matplotlib);
`check_detection_sensitivity.py` and the OFD scripts also plot with matplotlib.
